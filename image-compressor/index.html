Practical limits

  • Supported formats: JPEG and PNG (up to 20 files, ~50 MB each).
  • Everything runs locally in a Web Worker — the page stays responsive.
  • Codec modules (~2 MB) are fetched from esm.sh on first compression, so the first file needs a network connection.
  • PNG optimisation is lossless; JPEG uses the quality slider (MozJPEG).
  • If re-encoding cannot beat the original file, the original is kept.
